# Мой мир — сборка Android APK

Это проект Android-приложения: офлайн-прототип включён внутрь приложения, есть отдельный значок запуска. После установки запускается как обычное приложение, без выбора браузера.

## Как получить APK

**Этот архив — исходный проект, не APK.** В текущей среде нет Android SDK/Gradle и сетевого доступа, поэтому я не могу честно приложить уже собранный и проверенный APK. Сборка настроена через GitHub Actions.

1. На GitHub создайте пустой репозиторий.
2. Распакуйте архив и загрузите всё его содержимое в корень репозитория (обязательно вместе со скрытой папкой `.github`).
3. Откройте вкладку **Actions** и разрешите workflows, если GitHub попросит.
4. Выберите **Build My World APK** → **Run workflow**.
5. После успешной сборки откройте запуск workflow и скачайте артефакт **my-world-debug-apk**.
6. Распакуйте артефакт: внутри должен быть `app-debug.apk`. Передайте его на Android-телефон и установите.

Если сборка завершится ошибкой, откройте её журнал (лог) — по нему можно исправить конкретную проблему. Это debug APK для личной установки, не для Google Play.
